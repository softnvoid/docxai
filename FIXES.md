## Как использовать исправленный код

### 1. Настройка окружения
```bash
# Создайте .env файл с вашими credentials
cp .env .env.backup  # Сохраните текущий если есть
echo "yandexgpt_token=YOUR_TOKEN_HERE" > .env
echo "folder_id=YOUR_FOLDER_ID_HERE" >> .env
```

### 2. Установка зависимостей
```bash
pip install coolname requests python-docx pdf2docx
```

### 3. Подготовка конфигурации
Файлы `prompt.txt` и `instruction.txt` создадутся автоматически при первом запуске из `default_prompt.txt` и `default_instruction.txt`.

### 4. Запуск
```bash
# Положите ваш документ как test.docx в корень проекта
python src/docxai_process.py
```

### 5. Результат
- Обработанный файл: `test-<random-name>.docx`
- Лог выполнения: `docxai.log`
